Stored devices

The key is saved privately on this host. Cloud reports use the organization API token.

Add OpenHaystack tag

Use the 28-byte private key exported as standard base64 for your already-flashed tag. This does not flash hardware or sign in to Apple.

Connect Hubble

Create a token with read-devices and read-packets in Hubble Dashboard. This discovers and archives all devices in the organization. It does not register or reflash devices with Hubble.
